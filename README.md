# Python Loops & Automation: Temperature Analysis

This project is a Python-based tool to analyze weekly temperature data. It demonstrates the use of loops and conditional control statements like `break` and `continue`.

# 1. Project Tasks
* **Task 1:** Manual calculation of Maximum and Minimum temperatures (without using `max()` or `min()`).
* **Task 2:** Counting "Hot Days" (>30°C) while skipping others using the `continue` keyword.
* **Task 3:** An Alert System that stops processing using the `break` keyword if temperatures reach 40°C.

## 2. How to Run
1. Ensure you have Python installed.
2. Run the script via terminal:
   ```bash
